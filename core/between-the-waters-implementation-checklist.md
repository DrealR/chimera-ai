# Between the Waters — Corrigible Mirror Checklist

Use with [`corrigible-mirrors-and-shared-primes.md`](corrigible-mirrors-and-shared-primes.md).

Before calling an AI system corrigible, verify:

- [ ] active objective is inspectable;
- [ ] assumptions and confidence are visible;
- [ ] the user can reject a recommendation without punishment;
- [ ] consequential actions require explicit authorization;
- [ ] correction changes behavior in a declared scope;
- [ ] prior error and revision remain auditable;
- [ ] the system can stop;
- [ ] the user can export and leave;
- [ ] memory is bounded and governed;
- [ ] local operators can alter the shared protocol;
- [ ] slower human appeal can interrupt faster machine action;
- [ ] the system gives up a real optimization advantage when honoring correction.

Narrative inspiration is not implementation evidence. Every checked box needs a test or artifact.
